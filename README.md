# 駅メモUtilities for Ichihai1415

Android向け駅メモ支援アプリです。定期的に位置情報を取得し駅が変わったら通知するなど。


## 機能

以下の項目を駅メモ等の上に表示できます。上の ≡ の部分で移動ができます。駅メモUtilities の部分をタップすると表示を減らす/戻すことができます。長押しするとメイン画面を開きます。

- タイマー

5分連打支援です。メイン画面の `Timer Duration` で設定し、メイン画面の(Re)Start Timerかオーバーレイの(RE)STARTボタンを押すことでタイマーが開始されます。オーバーレイのRESETボタンを押すことでタイマー解除ができます。

終了時にバイブレーションや通知ができます。

- アクセス駅確認

[Seo-4d696b75 / station_database](https://github.com/Seo-4d696b75/station_database) のデータを [EkimemoDB2Voronoi](https://github.com/Ichihai1415/EkimemoDB2Voronoi) で変換したデータをもとに、位置情報からアクセスする駅を表示します。

駅が変わった時にバイブレーションや通知ができます。

その他座標、高度（H）、水平精度（A）、速度（S）が表示されます。


## 権限

- 詳細な位置情報（フォアグラウンド）
- 他のアプリに重ねて表示


## お知らせ

その他の機密情報を取得することも、位置情報を保存・送信することはありません。
