# 駅メモUtilities for Ichihai1415

Android向け駅メモ支援アプリです。定期的に位置情報を取得し駅が変わったら通知するなど。


## 機能

以下の項目をオーバーレイとして駅メモ等の上に表示できます。＿ の部分をタップすると表示を減らす/戻すことができます。↗の部分をタップすると駅メモ、長押しするとメイン画面を開きます。これらとボタンを除いた他の部分でオーバーレイの移動ができます。


- タイマー

5分連打支援です。メイン画面の `Timer Duration` で設定し、メイン画面の(Re)Start Timerかオーバーレイの(RE)STARTボタンを押すことでタイマーが開始されます。オーバーレイのRESETボタンを押すことでタイマー解除ができます。

終了時にバイブレーションや通知ができます。

- アクセス駅確認

[Seo-4d696b75 / station_database](https://github.com/Seo-4d696b75/station_database) のデータを [EkimemoDB2Voronoi](https://github.com/Ichihai1415/EkimemoDB2Voronoi) で変換したデータをもとに、位置情報からアクセスする駅を表示します。

駅が変わった時にバイブレーションや通知ができます。

その他、取得ソース（[G]: GPS, [N]: ネットワーク）、駅属性（T）、駅までの距離（D）、高度（H）、水平精度（A）、速度（S）が表示されます。

なお、開始直後は取得に時間がかかります。


## 権限

- 詳細な位置情報（フォアグラウンド）
- 他のアプリに重ねて表示


## 設定

自動で保存されます。一部は反映に特定の操作が必要です。

### Timer Duration

タイマーの時間です。

### Get Location Interval

位置情報取得間隔です。

### GPS Wait Time Before Use an Alternative

GPSの待機時間で、取得にこれ以上時間がかかるとネットワークを使用して取得します。

まだ仕様がよく分かっておらず短くすると挙動が怪しくなります。

### Enable Vibration

タイマー終了時や駅切り替わり時にバイブレーションを有効にするかどうかです。

### Enable Notification

タイマー終了時や駅切り替わり時に通知を有効にするかどうかです。

### Hide Location (overlay)

オーバーレイで位置情報を非表示にするかどうかです。長期的に使用しない場合などに有効です。

### Hide Timer (overlay)

オーバーレイでタイマーを非表示にするかどうかです。長期的に使用しない場合などに有効です。


## お知らせ

その他の機密情報を取得することも、位置情報を保存・送信することはありません。なお、ある程度詳細な位置情報が表示されるためスクリーンショットを撮る際は注意してください。


## 注意

- アプリ開発はほぼ初めてでAIと相談しながら作成しました。まだよくわかっていないところが多いのでバグも多いですがご了承ください。
- 駅取得について：GPSベースとネットワークベースの2種類があり、駅メモでどう使用されるか分かっていないため、駅が一致しないことがあります。

このように動作が不安定な部分があります。もし不具合があれば、また機能の要望があればXやIssuesなどで報告してくださると助かります。

### 例

- トンネルなど電波が不安定な場合に駅切り替わる所付近で正常に動作しない
- 全体的な挙動（固まって落ちるときがある）
- 非表示されるべきものが残る（位置情報取得終了後に駅表示が残るなど）
- 表示値のリセットが正常にできない場合がある（タイマー稼働中に駅が切り替わる際など）
